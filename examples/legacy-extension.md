# Legacy Chrome Extension (Mazda OAuth Helper)

> [!NOTE]
> This extension is no longer actively maintained. Use [OAuth Assist for HA](../README.md#oauth-assist-for-ha-chrome-and-firefox-extensions) instead, or the [manual sign-in](../README.md#manual-authentication).

> The chrome extension is tied to the folder location on your computer and may disappear if you move the folder.

1. Download the source code and find `./browser-extensions/chrome-extension/`.
2. Open Google Chrome and navigate to `chrome://extensions/` or Edge `edge://extensions/`.
3. Enable `Developer mode` in the top right.
4. Click `Load unpacked` and select the chrome-extension folder.
5. Start the authentication process in Home Assistant and choose **Automated sign-in (browser extension)**.
